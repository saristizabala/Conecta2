# 🔧 Conecta2 — Marketplace de Servicios

App que conecta personas que necesitan servicios del hogar (plomería, 
carpintería, aseo, costura, etc.) con personas que los ofrecen.

## ¿Qué hace?
- API REST completa para gestión de usuarios, servicios y solicitudes
- Arquitectura escalable con patrones Repository y Service Layer
- Despliegue en producción con Docker + Render

## Stack tecnológico
- Java · Spring Boot · PostgreSQL
- Docker · Render
- Scrum (metodología de desarrollo)

## Cómo ejecutarlo
```bash
# Requiere Java 17+ y PostgreSQL
./mvnw spring-boot:run
```

## Arquitectura
Backend RESTful con separación por capas: Controller → Service → Repository → DB.
Desarrollado bajo metodología Scrum con sprints documentados.

## Contexto
Proyecto académico — Ingeniería de Sistemas, Universidad Central (2024)
